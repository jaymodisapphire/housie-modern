# Modern Serverless Housie Game

Built with Next.js 15, React 19, Tailwind CSS, Upstash Redis, and Pusher. 
Designed specifically to avoid Vercel timeouts by using a serverless-friendly websocket and persistent state architecture.

## Setup
1. `npm install`
2. Copy `.env.example` to `.env.local` and add your Upstash & Pusher credentials.
3. `npm run dev`
